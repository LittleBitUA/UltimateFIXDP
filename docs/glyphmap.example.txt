; Example of UltimateFix\text\glyphmap.txt for UltimateFIXDP (the text overlay, see TEXT_OVERLAY.md).
; Copy it to <game folder>\UltimateFix\text\glyphmap.txt, save as UTF-8, and add the characters of your own font atlas.
;
; One line per character:   <character> = <cell>
;   <character>  the character itself, or U+XXXX (needed for ';' = U+003B and for the space = U+0020)
;   <cell>       the cell of the font atlas FONTWIDE: row * 64 + column, both counted from 0, a cell is 32 x 32 pixels.
;                Written as 0x.. (hexadecimal) or as a decimal number, 0..0x97F (64 columns x 38 rows).
; Cells below 0xE2 are narrow (the game draws the left 16 pixels and moves on by half a cell), cells from 0xE2 on are wide.
; A line that starts with ';' is a comment.
;
; Everything below this line down to the Cyrillic part is already built into the mod (the cells of the stock US atlas)
; and is listed here only to show it. Lines of this file win over the built-in ones.
